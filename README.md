# katya

## Центр практики · ноябрь 2026
`trainer.html`, `practice.js`, `practice.css` — темы и упражнения ученицы. Исходный словарь `data/katya.json` сохранён. `trainer-classic.html` сохраняет прежние режимы. Прогресс хранится только в браузере (`katya.practice.v2`), голос — `katya.speech.v2`. Xiaoyi приоритетен, фактические голоса предоставляет браузер. Порядок черт локальный; лицензии в vendor.
Проверки: `node tests/practice.cjs` и `node tests/speech.cjs`. Баланс, даты и отчёты редактируются в index.html.


## Иллюстрации тем · ноябрь 2026
В assets/topics/ — отдельная WebP-иллюстрация каждой словарной группы (имя файла = ID темы). Карточка темы и заголовок выбранной темы используют эту иллюстрацию. Изображения сгенерированы в стиле Chinese Storybook Ink & Wash, без текста; палитра соответствует кабинету ученика.
